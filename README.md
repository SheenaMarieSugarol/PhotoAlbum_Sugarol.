## 📖 **Project Description**

This project is a multi-page photo album website created using **HTML, CSS, and Laravel Blade templates**.  
It showcases different categories of visual content such as architectural infrastructures, cafes, museums, landscapes, and beaches.

The website includes:
- A welcoming homepage  
- Navigation menu linking to all categories  
- A themed design for each section  
- Styled image boxes and grid layouts  
- Footer section  

---

## 📂 **Pages and Descriptions**

### **1. Home Page (`home.blade.php`)**
The landing page that introduces users to the photo album.  
It contains the title, description, and navigation menu to explore other categories.

---

### **2. Architectural Infrastructures (`page1.blade.php`)**
A curated selection of global architectural wonders.  
This page highlights iconic structures where creativity meets engineering and timeless design.

---

### **3. Cafes (`page2.blade.php`)**
Displays well-known cozy cafés worldwide, featuring aesthetic interiors, signature designs, and relaxing atmospheres.

---

### **4. Museums (`page3.blade.php`)**
Showcases cultural and historical museums around the world, giving users a glimpse into art, heritage, and legacy.

---

### **5. Landscapes (`page4.blade.php`)**
Includes breathtaking landscapes such as mountains, lakes, skies, and natural formations that inspire serenity and adventure.

---

### **6. Beaches (`page5.blade.php`)**
Features famous beaches with clear waters, stunning coastlines, and peaceful tropical scenery.
